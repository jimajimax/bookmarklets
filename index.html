使い方

iPhone・iPad Safari
  1. 使用したいBookmarkletのボタンをタップしてコードをコピーします。
  2. Safariの共有ボタン、または「…」から「ブックマークに追加」を選択します。
  3. ブックマークを編集し、URL欄をすべて削除します。
  4. コピーしたBookmarkletコードをURL欄に貼り付けます。
  5. 実行したいページを開き、ブックマーク一覧から登録したBookmarkletをタップします。
ページをリロード・更新した場合は、再度Bookmarkletを実行してください。
iPhone・iPad Chromeなど
  1. 使用したいBookmarkletのボタンをタップしてコードをコピーします。
  2. ブラウザの「…」から「ブックマークに追加」を選択します。
  3. ブックマークを編集し、タイトルを好きな名前に変更します。
  4. URL欄をすべて削除し、コピーしたコードを貼り付けます。
  5. 実行したいページを開き、アドレスバーに付けた名前を入力します。
  6. 検索候補に表示されたBookmarkletをタップして実行します。
ページをリロード・更新した場合は、再度Bookmarkletを実行してください。
ブックマーク一覧から登録したBookmarkletを選択して実行する方法もあります。
Android
  1. 使用したいBookmarkletのボタンをタップしてコードをコピーします。
  2. ブラウザの「︙」から☆アイコンをタップしてブックマークを追加します。
  3. ブックマークを編集し、タイトルを好きな名前に変更します。
  4. URL欄をすべて削除し、コピーしたコードを貼り付けます。
  5. 実行したいページを開き、アドレスバーに付けた名前を入力します。
  6. 検索候補に表示されたBookmarkletをタップして実行します。
ページをリロード・更新した場合は、再度Bookmarkletを実行してください。
ブックマーク一覧から登録したBookmarkletを選択して実行することもできます。
PC（Chrome / Edge / Firefox / Safari）
  1. ブックマークバーを表示します。
  2. Bookmarkletボタンをブックマークバーへドラッグ＆ドロップします。
  3. 実行したいページを開きます。
  4. ブックマークバーから登録したBookmarkletをクリックします。
ページをリロード・更新した場合は、再度Bookmarkletを実行してください。
Windowsは Ctrl + Shift + B、Macは ⌘ + Shift + B でブックマークバーを表示できます。
その他のデバイス
  1. Bookmarkletコードをコピーします。
  2. ブラウザのメニューから「ブックマークに追加」を選択します。
  3. 追加したブックマークを編集します。
  4. URL欄をBookmarkletコードに置き換えます。
  5. 実行したいページでブックマークを開きます。
ページをリロード・更新した場合は、再度Bookmarkletを実行してください。
ブラウザによってはBookmarkletが正常に動作しない場合があります。その場合はSafariまたはChromeをお試しください。

個人情報を収集・保存することはありません。Bookmarkletの実行は利用者ご自身の責任において行ってください。
